# 安装、更新与本机资源

## 余记是什么

余记是 PWA：使用 HTML、CSS 和 JavaScript 编写的网页应用，由 iPhone 的浏览器引擎打开。应用外壳缓存支持离线打开，账目和头像保存在本机 IndexedDB，语音和截图识别资源保存在本机 Cache Storage。

主屏幕图标或 `.mobileconfig` Web Clip 指向固定 HTTPS 地址。描述文件提供全屏网页入口，不安装 Swift/Objective-C 编译的原生程序，也不包含账目。苹果支持这种网页 App 入口，因此不需要 App Store 上架、付费开发者账号或定期签名。

## 为什么重开后会升级

GitHub Pages 发布新版网页文件，Service Worker 联网检查并缓存新版外壳，之后重新打开会使用新版。更新仍然需要下载网页文件，只是不需要重新安装入口或描述文件。

账本存储身份不变，更新代码不会重新创建或覆盖账本。识别资源未变化时继续使用原来的缓存。更新后的版本号可在“我的”底部查看；设备仍显示旧版时，联网关闭后重新打开。

## 语音包下载、暂停与续传

从 v0.2.2 起，关闭语音浮层或切到其它页面会继续下载，顶部显示进度。点“暂停”才停止。重新进入语音入口会接上同一个任务，不会同时开启多份下载。

大文件按 2 MiB 片段下载，片段使用固定的资源校验值和序号保存。网络中断或应用退出后，点“继续”会跳过已保存的片段；正在接收但未保存的片段会重新下载。服务器不支持 HTTP Range 时，改为覆盖下载完整文件。

片段完整后合并到固定资源地址，再清理片段。合并期间会短暂同时保存片段和完整文件，完成后只留一份完整资源。“我的 → 本机储存”分别显示完整语音资源和续传片段用量，清理按钮删除两者，不影响账目、截图、头像或备份。

iOS 锁屏、切换到其它 App 或结束网页进程后可能暂停执行。余记不能保证像原生后台下载服务一样持续运行。

## 删除主屏幕入口会清掉模型吗

模型在手机本地的网页缓存中。网站数据的生命周期由 iOS/WebKit 管理，不能保证移除图标或 Web Clip 描述文件就同时清理所有缓存。要确定释放模型空间，请先使用余记里的“清理本机语音包与续传片段”。

清理 Safari 的整个网站数据可能同时删除账本；这种操作前先导出完整 `.yuji` 备份。账目不会自动上传到服务器。

## 快捷输入是什么

“截图记账”从图片分享菜单接收付款截图，在本机提取文字，把结果交给余记核对入账。“本机语音入口”快速打开余记的长按说话页面，可放在快捷指令小组件中，或通过 Siri 启动。

先下载 `.shortcut` 文件，在“文件 → 下载项”打开并添加到系统快捷指令。公开部署使用带附件文件名的 GitHub Release 下载地址，避免把签名后的二进制当作网页文字展示。具体步骤见 [快捷输入](SHORTCUTS.zh-CN.md)。

原生应用可以通过 App Intents、分享扩展、原生小组件等更深地接入系统；纯 PWA 采用用户主动触发的快捷指令桥接，不会后台读取微信、支付宝或银行流水。
