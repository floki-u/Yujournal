# 快捷输入

快捷指令不是另外手动记一遍账。它把系统的截图文字识别结果，或录入入口，交给余记；最终在余记核对清单并一次确认。

## 截图分享

在“我的 → 快捷指令与小组件入口”等待文件准备完成，点“安装 / 分享截图指令”，在系统面板选择“存储到文件”；若面板提供“快捷指令”，可以直接选择。也可点“保存截图指令到文件”，再在“文件”中打开 `.shortcut` 并添加。主屏幕入口不能保存时，可在 Safari 打开安装页完成相同操作。安装一次后，从截图缩略图、照片或其他 App 的图片分享菜单选择“余记 · 截图记账”。

从 v0.2.3 起，安装按钮不再打开 GitHub Release 或附件 CDN。应用先从自己的同源 `shortcuts/` 文件准备并校验安装文件，再在用户点击时打开系统分享，或保存本机 Blob 文件。已缓存外壳包含两个约 22 KB 的签名文件。`.shortcut` 是二进制，不应直接当网页展示。重新生成签名文件后，须同步更新 `src/lib/quick-input.js` 的预期 SHA-256。

这条指令接收分享的图片，在系统中提取文字，将带有余记标记的结果复制到**仅本机**剪贴板，再打开录入入口。它不上传图像或文字，不需要手输金额，也不发送金额到网址查询参数。

网页不能查询系统是否安装了某条快捷指令，也不能静默更改 iOS 快捷指令配置。余记的“显示快捷输入入口”开关只控制应用自己的接收按钮。首次添加仍由你在 iOS 确认。

如果打开的是 Safari，而你的历史账本在主屏幕 Web Clip，请回到主屏幕“余记”，点“接收快捷输入”。两种入口的数据分区由 iOS 决定，不能假装后台已写入主屏幕账本。核对后再“全部确认入账”；这一步保护金额准确性。

## 小组件 / 本机语音

“余记 · 本机语音”只打开应用的语音录入入口，不使用系统云端听写。把它加入苹果“快捷指令”小组件，可较快进入长按说话。模型在余记首次按需准备，约 98 MiB；原始录音不保存、不上传。

纯 PWA 不能在系统后台监听每次截图、读取支付 App 流水或注册原生图片分享扩展，也无法在网页关闭时任意修改它的 IndexedDB。这里采用的是你主动触发的系统分享流程，识别完成后确认入账。

## 透明模板

`shortcuts/templates/` 为可阅读的原始 plist。`scripts/create-shortcuts.py` 可重新生成，macOS 使用 Apple `shortcuts sign --mode anyone` 产生分享文件。Apple 会接收这些**静态工作流模板**用于签名验证；模板不含用户真实图片、录音、账目、密钥或联系人。
