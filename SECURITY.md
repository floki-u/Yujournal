# Security reports

Use **Security → Report a vulnerability** when private reporting is enabled: [private report](https://github.com/floki-u/Yujournal/security/advisories/new).

Do not attach real ledgers, payment images, passwords, device IDs or decrypted backups. Use synthetic reproductions. If private reporting is unavailable, open an issue asking for a private channel without publishing exploit details or sensitive data.

Supported: 0.1.x. This early release has no response-time or audit-certification promise. Trusted same-origin code can access local browser data. Plain backups detect corruption; encrypted backups add authentication. Keep file backups and review installation-profile contents/target URL.
